## Variant

`solid`는 화면에서 가장 강한 한 가지 동작(허용, 저장)에 써요. 잉크색으로 채워요. 나머지는 `outline`(기본), 덜 중요하면 `ghost`, 글 사이의 동작은 `link`예요.

<Demo client:load name="button-variants" />

## Size

`xs`는 채팅의 작은 버튼(24px), `sm`은 카드의 버튼(28px, 기본), `md`는 설정과 대화상자예요.

<Demo client:load name="button-sizes" />
