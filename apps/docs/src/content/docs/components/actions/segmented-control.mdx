## 접근성

`role="group"`에 `label`이 이름으로 붙고, 각 버튼은 `aria-pressed`로 골랐는지 알려요. ←/→로 버튼 사이를 옮겨요. 마우스를 올려도 고른 것의 모양은 바뀌지 않아요.
