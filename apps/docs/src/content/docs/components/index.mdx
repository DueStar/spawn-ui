---
title: 전체 컴포넌트
---

spawn 화면에 쓰이는 모든 컴포넌트를 담아 가는 중이에요. 지금은 1단계(기초 · 동작 · 상태)예요. 다음 단계는 카드, 메뉴, 대화상자 같은 담는 것들, 그다음 spawn만의 세션 · 게임 · 채팅 컴포넌트예요.

## 기초

- [Icon](./foundations/icon/) — Phosphor 아이콘을 spawn의 굵기 하나와 크기 세 단계로 그려요.

## 동작

- [Button](./actions/button/) — 누르면 무언가 하는 글자 버튼. 노랑은 쓰지 않아요.
- [IconButton](./actions/icon-button/) — 아이콘만 있는 버튼. 이름은 말하고, 마우스를 올리면 보여요.
- [SegmentedControl](./actions/segmented-control/) — 몇 가지 중 하나를 나란히 놓고 골라요. 고른 것은 옅은 바탕과 밝은 글자예요.
- [Switch](./actions/switch/) — 설정을 바로 켜고 꺼요. 켜진 설정은 고른 것이라 노랑이에요.
- [Checkbox](./actions/checkbox/) — 여러 개를 함께 고를 수 있을 때. 질문 카드의 여러 개 고르기에서 써요.
- [RadioGroup](./actions/radio-group/) — 목록에서 하나를 골라요. 질문 카드의 선택지에서 써요.

## 상태

- [StatusDot](./status/status-dot/) — 6px 점 하나로 상태나 등급을 보여요. 점만으로 말하지 않게 글이 함께 있어요.
- [Tag](./status/tag/) — 가는 선 하나로 두른 작은 이름표. 채우지 않아요.
- [Pill](./status/pill/) — 세션의 상태를 점과 글자로 보여요.
- [Badge](./status/badge/) — 보상의 노랑 위에 둥근 배지. 새 포켓몬, 개수.
- [Meter](./status/meter/) — 얇은 막대. 컨텍스트(HP), 사용량, 포켓몬 능력치.

## 담는 것

- [Card](./containers/card/) — 무언가를 담는 상자. 위젯 카드, 채팅 카드, 코드·diff를 담는 칸.
- [Notice](./containers/notice/) — 조용한 한 줄. 상태, 힌트, 날짜, 경고. 줄을 바꿔 다 보여 줘요.
- [EmptyState](./containers/empty-state/) — 아직 아무것도 없을 때(또는 불러오는 중일 때) 그 자리에 보이는 것.
- [Banner](./containers/banner/) — 사람이 봐야 할 것. 언제나 주황 가는 선이고, 노랑은 쓰지 않아요.
- [ListRow](./containers/list-row/) — 목록의 한 줄. 컨트롤이 붙은 설정 줄, 또는 골라서 여는 줄.
- [Toolbar](./containers/toolbar/) — 페이지 위의 필터 줄. 아래에 가는 선, 좁으면 줄을 바꿔요.
- [TextInput](./containers/text-input/) — spawn의 글 입력란. 포커스는 테두리가 밝아지는 것으로 보여요.
- [SearchField](./containers/search-field/) — 목록이나 격자 위의 검색칸.
- [FindBar](./containers/find-bar/) — 대화나 터미널에서 찾기. 오른쪽 위에 떠요.
- [Dialog](./containers/dialog/) — 앱 위에 뜨는 창. Tab이 안에서만 돌고, Esc나 바깥을 누르면 닫히고, 닫히면 연 버튼으로 포커스가 돌아가요.
- [Menu](./containers/menu/) — 버튼에서 열리는 선택지 목록. 화살표로 움직이고, Enter로 고르고, Esc로 닫아요.
- [Tooltip](./containers/tooltip/) — 마우스를 올리거나 키보드로 닿으면 뜨는 짧은 설명. spawn은 말씀하실 때까지 기본 title을 그대로 써요.
- [Tabs](./containers/tabs/) — 탭. 화살표로 움직이고, 고른 탭의 내용을 보여 줘요.
