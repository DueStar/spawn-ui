---
title: 전체 컴포넌트
---

spawn 화면에 쓰이는 모든 컴포넌트를 담아 가는 중이에요. 지금은 1단계(기초 · 동작 · 상태)예요. 다음 단계는 카드, 메뉴, 대화상자 같은 담는 것들, 그다음 spawn만의 세션 · 게임 · 채팅 컴포넌트예요.

## 기초

- [Icon](./foundations/icon/) — Phosphor 아이콘을 spawn의 굵기 하나와 크기 세 단계로 그려요.

## 동작

- [Button](./actions/button/) — 누르면 무언가 하는 글자 버튼. 노랑은 쓰지 않아요.
- [IconButton](./actions/icon-button/) — 아이콘만 있는 버튼. 이름은 말하고, 마우스를 올리면 보여요.
- [SegmentedControl](./actions/segmented-control/) — 몇 가지 중 하나를 나란히 놓고 골라요. 고른 것은 옅은 바탕과 밝은 글자예요.
- [Switch](./actions/switch/) — 설정을 바로 켜고 꺼요. 켜진 설정은 고른 것이라 노랑이에요.
- [Checkbox](./actions/checkbox/) — 여러 개를 함께 고를 수 있을 때. 질문 카드의 여러 개 고르기에서 써요.
- [RadioGroup](./actions/radio-group/) — 목록에서 하나를 골라요. 질문 카드의 선택지에서 써요.

## 상태

- [StatusDot](./status/status-dot/) — 6px 점 하나로 상태나 등급을 보여요. 점만으로 말하지 않게 글이 함께 있어요.
- [Tag](./status/tag/) — 가는 선 하나로 두른 작은 이름표. 채우지 않아요.
- [Pill](./status/pill/) — 세션의 상태를 점과 글자로 보여요.
- [Badge](./status/badge/) — 보상의 노랑 위에 둥근 배지. 새 포켓몬, 개수.
- [Meter](./status/meter/) — 얇은 막대. 컨텍스트(HP), 사용량, 포켓몬 능력치.

## 담는 것

- [Card](./containers/card/) — 무언가를 담는 상자. 위젯 카드, 채팅 카드, 코드·diff를 담는 칸.
- [Notice](./containers/notice/) — 조용한 한 줄. 상태, 힌트, 날짜, 경고. 줄을 바꿔 다 보여 줘요.
- [EmptyState](./containers/empty-state/) — 아직 아무것도 없을 때(또는 불러오는 중일 때) 그 자리에 보이는 것.
- [Banner](./containers/banner/) — 사람이 봐야 할 것. 언제나 주황 가는 선이고, 노랑은 쓰지 않아요.
- [ListRow](./containers/list-row/) — 목록의 한 줄. 컨트롤이 붙은 설정 줄, 또는 골라서 여는 줄.
- [Toolbar](./containers/toolbar/) — 페이지 위의 필터 줄. 아래에 가는 선, 좁으면 줄을 바꿔요.
- [TextInput](./containers/text-input/) — spawn의 글 입력란. 포커스는 테두리가 밝아지는 것으로 보여요.
- [SearchField](./containers/search-field/) — 목록이나 격자 위의 검색칸.
- [FindBar](./containers/find-bar/) — 대화나 터미널에서 찾기. 오른쪽 위에 떠요.
- [Dialog](./containers/dialog/) — 앱 위에 뜨는 창. Tab이 안에서만 돌고, Esc나 바깥을 누르면 닫히고, 닫히면 연 버튼으로 포커스가 돌아가요.
- [Menu](./containers/menu/) — 버튼에서 열리는 선택지 목록. 화살표로 움직이고, Enter로 고르고, Esc로 닫아요.
- [Tooltip](./containers/tooltip/) — 마우스를 올리거나 키보드로 닿으면 뜨는 짧은 설명. spawn은 말씀하실 때까지 기본 title을 그대로 써요.
- [Tabs](./containers/tabs/) — 탭. 화살표로 움직이고, 고른 탭의 내용을 보여 줘요.

## spawn · 세션

- [SessionRow](./sessions/session-row/) — 세션 목록의 한 줄. 포켓몬, 이름, 상태, HP. Enter로 열고 F2로 이름을 바꾸고, ×는 한 번 묻고 닫아요.
- [SessionPicture](./sessions/session-picture/) — 세션이 누구인지: 포켓몬, 또는 포켓몬이 없을 때의 표시.
- [Rail](./sessions/rail/) — 접힌 왼쪽 패널. 56px 기둥에 버튼과 세션.
- [ListHead](./sessions/list-head/) — 세션 목록의 머리. 간략/상세가 먼저, 버튼은 오른쪽.
- [Launcher](./sessions/launcher/) — 새 세션 시작하기와 폴더 열기, 이어하기.
- [Account](./sessions/account/) — 로그인 버튼, 또는 둥근 프로필.
- [SessionHeader](./sessions/session-header/) — 세션 위의 줄: 누구인지, 어디서 일하는지, 도구와 ×.
- [PaneHead](./sessions/pane-head/) — 나란히 보기에서 칸 하나의 머리.
- [AppHeader](./sessions/app-header/) — 창의 머리와 오른쪽 위 줄. 끌면 창이 움직이고, 버튼은 그대로 눌려요.
- [ResizeHandle](./sessions/resize-handle/) — 끌어서 폭을 바꾸는 가장자리. ← →로 움직이고 Home이나 두 번 누르면 처음 폭.
- [DragCard](./sessions/drag-card/) — 목록 밖으로 끌 때 포인터를 따라오는 작은 카드.
- [DropZone](./sessions/drop-zone/) — 끌어 놓을 자리를 밝혀 보여 줘요.
- [QueueStrip](./sessions/queue-strip/) — Claude가 일하는 동안 기다리는 메시지들.
- [UpdateButton](./sessions/update-button/) — 업데이트. 상태를 언제나 글로 말해요.
- [TextSizeControl](./sessions/text-size-control/) — − 가 + : 앱 전체 글자 크기(80~130%).
- [UsageBars](./sessions/usage-bars/) — 요금제 한도: 이름 · 막대 · % · 초기화 시각.

## spawn · 게임

- [PokemonSprite](./game/pokemon-sprite/) — 포켓몬 그림. 부드럽게, 넘치지 않게. 딱딱한 픽셀은 야생 줄에서만.
- [TierLabel](./game/tier-label/) — 등급: 점과 글자. 색만으로 말하지 않아요.
- [TypeTag](./game/type-tag/) — 포켓몬 타입: 그 타입 색의 가는 선 태그.
- [MonCell](./game/mon-cell/) — 도감·박스·고르기의 포켓몬 칸. 고른 칸은 1px 노란 테두리.
- [DexStrip](./game/dex-strip/) — 왼쪽 패널의 도감 줄: 몇 마리, 최근에 잡은 것.
- [StatTile](./game/stat-tile/) — 도감 위의 숫자 하나: 이름, 큰 숫자, 얇은 막대.
- [WildRow](./game/wild-row/) — 채팅에서 지나가며 만난 야생 포켓몬.
- [CatchToast](./game/catch-toast/) — 잡음·도망·레벨업 카드. 글자 크기를 따라가지 않아요.
- [LeaderboardRow](./game/leaderboard-row/) — 랭킹의 한 줄. 1~3등은 메달.
- [LogRow](./game/log-row/) — 오늘의 기록 한 줄과 날짜 머리.
- [StepCount](./game/step-count/) — 한 턴에 걸은 걸음 수.
- [DexDetailCard](./game/dex-detail-card/) — 도감과 박스의 포켓몬 상세: 그림, 이름, 정보.
- [PatchNotes](./game/patch-notes/) — 새로워진 점. 릴리스를 접었다 펴요.

## spawn · 채팅

- [Prose](./chat/prose/) — 앱이 렌더링한 Markdown을 spawn의 읽기 글꼴로.
- [CodeBlock](./chat/code-block/) — 코드를 터미널 바탕의 칸에. 언어와 복사.
- [MdDoc](./chat/md-doc/) — 채팅에 나온 Markdown 파일. 문서/원문.
- [UserMessage](./chat/user-message/) — 보낸 메시지. 대기 중이면 흐리게, 글로도.
- [TurnHead](./chat/turn-head/) — 한 턴의 머리(누가 답하는지)와 끝줄(시간, 도구, 복사). TurnFoot도 여기.
- [ThinkingRow](./chat/thinking-row/) — 생각 블록과 받는 중인 답(LiveBubble).
- [WorkingLine](./chat/working-line/) — 일하는 중·기다리는 중 줄과 새 메시지 알약(JumpPill).
- [ToolRow](./chat/tool-row/) — 도구 호출 한 줄. 펼치면 한 일이 보여요.
- [ShellRow](./chat/shell-row/) — `!` 명령: 작은 터미널 칸.
- [DiffBlock](./chat/diff-block/) — 파일의 변경: 이름, 줄 수, 색 띠 줄.
- [AnswerCard](./chat/answer-card/) — Claude가 채팅에서 묻는 것: 권한, 질문, 계획. 기다리는 동안 주황.
- [Composer](./chat/composer/) — 입력창. Enter 보내기, Shift+Enter 줄바꿈, 한글 조합 중 Enter는 무시. 보내기가 유일한 노랑.
- [ControlRow](./chat/control-row/) — 입력창 아래 줄: 모델, 생각 정도, 권한 모드.
- [FileChip](./chat/file-chip/) — 파일 칩. 이름이 보이고 전체 경로는 title.
- [ImageChip](./chat/image-chip/) — 그림 칩과 썸네일. 누르면 크게.
- [SuggestionList](./chat/suggestion-list/) — @멘션과 /명령 목록. 입력창이 움직여요.
- [LinkCard](./chat/link-card/) — 링크 미리보기 카드.
- [AgentChip](./chat/agent-chip/) — 일하는 보조 에이전트 칩.
- [SidePanel](./chat/side-panel/) — 채팅 오른쪽 칸(변경 사항, 에이전트).
- [Lightbox](./chat/lightbox/) — 사진을 크게. ← →로 넘겨요.
