## Variant

`solid` is the one strongest action on a screen (allow, save), filled with ink. The rest are `outline` (the default), `ghost` when quieter, and `link` for an action inside text.

<Demo client:load name="button-variants" />

## Size

`xs` is the chat's small buttons (24px), `sm` a card's (28px, the default), `md` settings and dialogs.

<Demo client:load name="button-sizes" />

## Disabled

Disabled, it fades and a press does nothing.

## Accessibility

Always a `<button>`, `type="button"` by default so it never submits a form by accident. Keyboard focus shows the one focus ring.
