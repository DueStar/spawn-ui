## Steps

Nine text steps. 100 % is the default; spawn's text size setting moves them from 80 % to 130 %.

## Weights

| Token | Value | Used for |
|---|---|---|
| `--w-mono` | 380 | code |
| `--w-body` | 400 | body |
| `--w-name`, `--w-strong` | 500 | names, emphasis |
| `--w-head` | 600 | headings, the wordmark |

## Typefaces

- Text: Pretendard (Korean), then Malgun Gothic · Apple SD Gothic Neo
- Code: Monaspace Neon, then Consolas · SF Mono
