spawn-ui는 [spawn](https://github.com/DueStar/spawn)의 디자인 시스템이에요. spawn은 Claude Code 세션을 포켓몬과 함께 쓰는 데스크톱 앱이에요. 세션이 일하는 동안 포켓몬이 함께 일하고, 기다리는 시간에 도감을 채워요.

spawn-ui에는 세 가지가 있어요.

- **`@spawn-ui/tokens`** — 색, 글꼴, 크기, 모서리, 움직임 값. spawn이 쓰는 값 그대로예요.
- **`@spawn-ui/react`** — 컴포넌트. 버튼처럼 흔한 것부터 세션 줄, HP 막대, 도감 칸, 채팅의 권한 카드까지, spawn 화면에 쓰이는 걸 모두 담아요.
- **이 문서** — 각 컴포넌트를 실제로 띄워 보고, 글자 크기를 바꿔 보고, 속성을 확인할 수 있어요.

## 왜 만들었나

spawn은 화면마다 CSS를 직접 그려 왔어요. 그러다 보니 같은 버튼이 이름만 다르게 여러 벌 생겼어요. 조사해 보니 73가지 모양이 257번 따로 정의돼 있었어요. 자세한 숫자는 [왜 spawn-ui인가](../why/)에 있어요.

반대로 spawn에는 테스트로 지켜 온 규칙이 있었어요. "노랑은 고른 것에만", "포커스 링은 하나", "본문은 4.5:1 이상" 같은 것들이에요. spawn-ui는 이 규칙을 그대로 가져와서 컴포넌트 하나하나에 테스트로 걸어 둬요. 규칙을 어기는 컴포넌트는 만들어지지 않아요.

## 원칙

- **spawn의 것** — 범용 라이브러리가 아니라 spawn의 차분한 어두운 화면을 위한 시스템이에요.
- **실제로 쓰는 것** — 문서에 있는 컴포넌트가 곧 spawn이 쓰는 컴포넌트예요. 그림이나 복사본이 아니에요.
- **화면은 그대로** — spawn을 spawn-ui로 옮겨도 픽셀이 바뀌지 않아요. 바꾸는 건 따로 정해서 해요.
