---
title: 움직임
description: 짧고 조용한 전환
---

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ease` | `cubic-bezier(0.2, 0, 0, 1)` | 모든 전환 |
| `--dur-fast` | 120ms | 놓은 줄이 제자리로, 칸이 밝아짐 |
| `--dur-base` | 180ms | 이웃 줄이 비켜남, 스위치 |

- 잘라서 숨기기보다 통째로 넣고 빼요. 줄이 반쯤 잘린 채 움직이지 않아요.
- 사용자가 받아들인 움직임은 다른 작업 중에 바꾸지 않아요.
- `prefers-reduced-motion: reduce`이면 모든 전환과 애니메이션이 멈춰요.
