# @spawn-ui/react

## 0.2.0

### Minor Changes

- Containers: Card, Notice, EmptyState, Banner, ListRow, Toolbar, TextInput, SearchField, FindBar, Dialog, Menu, Tooltip, Tabs (with TabPanel); the scrollbar utility (`sp-scroll--0|6|8|10`); PortalProvider, so popups open where a preview's text size reaches them.

## 0.1.0

### Minor Changes

- First release, stage one: Icon, VisuallyHidden (foundations); Button, IconButton, SegmentedControl, Switch, Checkbox, RadioGroup (actions); StatusDot, Tag, Pill, Badge, Meter (status). Every stylesheet is checked against spawn's rules (yellow, weights, radii, focus ring, reduced motion).

### Patch Changes

- Updated dependencies
  - @spawn-ui/tokens@0.1.0
